Reference file for Claude Code (from Charlie's Master Content Plan doc, Nov 8, 2026). Open only the section a task needs.

## Build queue

One ordered queue, no dates. One item per session. No live URL changes, no new redirects.

1. Install the article standard as skills and save-time gates. No new page until the gates pass on a test page.
2. Housekeeping: date-page series paused after post 19 (no post 20); sitemap has no redirecting URL.
3. 70s Christmas Songs (time-sensitive).
4. Pillars first:
   1. Retarget Best Songs of the 70s to "70s songs".
   2. 70s Bands hub: genre sections, links to every band and artist page.
   3. Build the 70s Rock Bands pillar.
   4. 70s Number One Hits hub: links to Years, the Birthday #1 Song Finder and the date pages; rework the Birthday tool.
   5. Listen Now radio: answer-first article section for "70s hits".
   6. Retarget Disco, Soul, Pop, Soft Rock and Funk pages.
5. Then a fixed rotation, one item per session:
   1. Band page (bands-queue.md, highest volume first)
   2. Artist page (artists-queue.md, highest volume first)
   3. New spoke from the keyword table
   4. Band page
   5. Artist page
   6. Upgrade an existing page to the standard (pages Google already ranks first: YMCA, How Can You Mend a Broken Heart, Somebody to Love; then the live band retitles)
   7. Linking pass on one pillar

Never two pages in the same genre back to back. Each new band or artist page links down to every song story already on the site for that act, and those song pages get a link back up in the same session. When a queue runs out, research new rows in DataForSEO and add them.

## Article standard

Every new article, and every existing page when upgraded, meets the ClassicRockArtists.com standard, written for this site's intent. Enforced by save-time checks.

| Element | Rule |
| --- | --- |
| Focus keyword | Highest-volume real phrasing across Google and AI search, checked in DataForSEO (US, Canada, UK) before writing; used naturally, never forced ("Song YMCA" is the example to avoid) |
| Anti-stuffing gate | Same limits as ClassicRockArtists; a failing page is not saved |
| Answer first | First two sentences answer the search: who sang it, who wrote it, the year, the peak, or the act's biggest hits |
| Facts box | Under the intro. Song: writer, artist, release date, Hot 100 peak, weeks at #1. Artist or band: active years, genre, biggest 70s hits, #1 count |
| Listen | Listen button at the top that plays in place; shared continuous player for every list; official or label uploads only |
| Writing | One sentence per paragraph, no em dashes, H3s to break long sections, no lyrics, no first-person concert claims |
| Sources | Named and opened; Wikipedia never the only source; chart data from data/billboard credited to the methodology page |
| Trust | Byline "By Charlie" linked to the author page, published date and updated date |
| Structure | Collapsible table of contents, FAQ that adds facts not in the body, You Might Also Like cards |
| Links | Up to the pillar, down to every related song story, 2 to 4 sideways, one to the radio or a tool; each target once; never link to classicrockartists.com |
| Schema | Per page type (below), checked by a schema gate on save |
| Verify | Live check on desktop and at 390px; nothing goes live without Charlie's review |

### Schema by page type

All pages also carry BreadcrumbList and the site's Person author (Charlie).

| Page type | Schema |
| --- | --- |
| Song story | BlogPosting + MusicRecording (byArtist, inAlbum, datePublished, recordingOf MusicComposition with composer) + VideoObject for the embed + FAQPage |
| Artist or band songs page | BlogPosting + about: MusicGroup or Person (genre, foundingDate, sameAs Wikipedia and MusicBrainz) + ItemList of MusicRecording + FAQPage |
| Playlist page (love songs, Christmas, yacht rock) | BlogPosting + MusicPlaylist (numTracks, track list of MusicRecording) + FAQPage |
| Soundtrack or album page | BlogPosting + MusicAlbum (albumProductionType, byArtist, datePublished, track list) + FAQPage |
| Music TV page (Soul Train, American Bandstand) | BlogPosting + about: TVSeries + VideoObject for clips + FAQPage |
| Pillar or hub page | CollectionPage + ItemList of the pages it links to |
| Chart-data page (#1 hits, years) | BlogPosting + ItemList of MusicRecording + Dataset (Billboard data, methodology link) |
| Quiz and trivia | Quiz for the scored quiz; FAQPage for trivia lists |
| Tools and radio | WebApplication |

Charlie's sites competing for the same searches is fine: each site builds its own best page, with no links between them.
